OEIS A378495, FORMULA (revision #70): refutation and correction

Haobo Ma, Wenlin Zhang

论文

这篇短文研究：重新排列对象且不让任何对象留在原位时，禁止不同长度的大循环，会使排列数相差多少。Haobo Ma 与 Wenlin Zhang 指出，一个已发表的预测取错了数列下标，另一个则成立，并解释了小规模的例外。他们给出自足的计数论证，同时将结果归功于先前作者。

给有标号的对象重新安排位置，称为置换。沿各对象的去向追踪，会得到互不相交的环，即循环；长度为一意味着对象不动。没有一循环的置换称为错排。记 n 个标号的错排总数为 Dₙ；对 2 ≤ k ≤ n，T(n,k) 表示还不含 k 循环的错排数。这些数构成 Peter Kagey 的 OEIS 三角表 A378495，本文针对2026年10月17日第70版。首列人为规定为零，并非禁止一循环的实际计数。比较各列，就是比较不同禁令排除了多少错排。

作者证明，n ≥ 5 时，T(n,n−1) − T(n,n−2) = n!/[2(n−2)]；n! 是 n 个标号的全部置换数。这等于 A238474 在下标 n−3 处的绝对值，而非预测的 n−4，下标沿用该数列从零开始的约定。原式在 n = 4 成立，却对所有 n ≥ 5 失败。另一预测无需修改：T(n,n−2) − T(n,n) = (n−3)!(n−4)(n−1)/2，适用于 n ≥ 5；n = 4 时两个差均为3。文章称，找到的最早证明及修正来自 Lien-Hung Su 于2026年10月18日的预印本，Ahaan Kallat 于10月29日给出较晚的独立证明。

关键是数禁令排除了什么。循环若占用超过一半的标号，就不可能另有同长度循环。因此，选其标号、排好环上次序、再将剩余标号错排，每个被排除的置换恰好数一次。对最后三列，含全部 n 个标号的循环有 (n−1)! 个。含 n−1 个标号的循环会留下一个不动的对象，故错排中不存在。含 n−2 个标号的循环留下两个必须互换的对象；选择这对对象并排列其余循环，得到 n!/[2(n−2)] 个。将排除数相减，两条公式随即得到，共同总数 Dₙ 抵消。

五个对象给出具体反例。错排只能是一个五循环，或一个三循环加一个二循环，分别有24个和20个。因此 T(5,3)、T(5,4)、T(5,5) 依次为24、44、20；相邻差是20，原下标却给出6。四个对象解释了边界：共有六个四循环，以及三个由两次互换组成的错排。若先选一次互换，后一类的每个排列会被数两遍，唯一性论证失效。此时三列为6、9、3，两个差均为3。

文章还讨论 n ≥ 3 时每行最大公约数为 n−1 的预测。这既要求 n−1 整除每项，也要求没有更大的公因子。文中自行证明前一方向：先选择指定标号所在的循环，再完成剩余排列，每种循环长度的计数因子均含 n−1。另一方向引用 Su 的定理，并列出 Kallat 的另一证明。最后三列不足以解决此问题：n = 7 时，它们的最大公约数为18，全行的却是6。

作者报告直接枚举到 n = 9、递推计算到 n = 80，这些仅核对有限范围；一般差值公式由书面计数证明支持。文章描述的固定版本 Lean 声明，分别表达以 n = 5 否定原相邻差公式，以及对所有 n ≥ 5 成立、采用有理数减法的末列差公式。所述 Lean 覆盖范围不包括修正后的相邻差公式、一般长循环计数或行最大公约数定理。本文意义在于精确修正并解释边界，而非给这些差值提出仍待证明的答案。关联数列条目的其他陈述不在本文范围内。
