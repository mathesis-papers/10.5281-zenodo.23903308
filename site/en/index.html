OEIS A378495, FORMULA (revision #70): refutation and correction

Haobo Ma, Wenlin Zhang

Paper

This note asks how counts of rearrangements with no object left in its original place change when different large circular exchanges are forbidden. Haobo Ma and Wenlin Zhang show that one published prediction uses the wrong sequence index, while another is correct, and explain a small-size exception. They give a self-contained counting argument while crediting earlier authors for the results.

A rearrangement of labeled objects is a permutation. Following where each object goes breaks it into disjoint loops, called cycles; a one-object loop means something stays put. A permutation without such loops is a derangement. Write Dₙ for their total number on n labels, and T(n,k) for the number also avoiding cycles of length k, for 2 ≤ k ≤ n. These counts form Peter Kagey’s OEIS triangle A378495, here considered at revision 70 of October 17, 2026. Its first column is conventionally zero, not the literal count avoiding one-cycles. Comparing columns measures how many derangements different cycle prohibitions remove.

The authors establish that, for n ≥ 5, T(n,n−1) − T(n,n−2) = n!/[2(n−2)], where n! counts all permutations of n labels. This equals the absolute value of sequence A238474 at index n−3, rather than the conjectured n−4, using its published starting index zero. The printed prediction fails for every n ≥ 5, although it holds at n = 4. The other prediction is correct: T(n,n−2) − T(n,n) = (n−3)!(n−4)(n−1)/2 for n ≥ 5. At n = 4, both differences are 3. The manuscript credits Lien-Hung Su’s October 18, 2026 preprint as the earliest proof found of these results and the correction, and Ahaan Kallat’s October 29 preprint as a later independent proof.

The mechanism is to count what each restriction excludes. A cycle longer than half the available labels cannot coexist with another of the same length. Choosing its labels, ordering them around a circle, and deranging the remaining labels therefore counts each excluded permutation exactly once. For the final three columns, a cycle using all n labels removes (n−1)! possibilities. A cycle using n−1 labels cannot occur in a derangement: the remaining object would stay fixed. A cycle using n−2 labels leaves two objects that must exchange places. Choosing that pair and cyclically ordering the others removes n!/[2(n−2)] possibilities. Subtracting these excluded counts gives both identities; the common total Dₙ cancels.

Five objects provide a concrete counterexample. Every derangement is either one five-cycle or a three-cycle together with a two-cycle; these types have respectively 24 and 20 possibilities. Thus T(5,3), T(5,4), and T(5,5) are 24, 44, and 20. The adjacent difference is 20, whereas the printed sequence index gives 6. Four objects explain the boundary: there are six four-cycles and three permutations consisting of two exchanges. Selecting one exchange would count each permutation of the second type twice, invalidating the uniqueness argument. The entries are then 6, 9, and 3, and both differences are 3.

The note also discusses the prediction that each row’s greatest common divisor is n−1 for n ≥ 3. This requires both that n−1 divide every entry and that no larger common divisor exist. Its own argument proves the first direction: choose the cycle containing a specified label, then complete the permutation; the counting factor for every possible cycle length contains n−1. The reverse direction relies on Su’s theorem, with Kallat supplying another proof. The final three columns alone are insufficient: at n = 7 their greatest common divisor is 18, while the full row’s is 6.

The authors report direct enumeration through n = 9 and recurrence calculations through n = 80, which check only finite ranges. The general difference identities rest on the written counting proof. They describe pinned Lean declarations expressing the printed adjacent formula’s refutation with witness n = 5 and the terminal identity for all n ≥ 5, using rational subtraction. That stated Lean coverage does not include the corrected adjacent identity, the general long-cycle count, or the row-gcd theorem. The significance is a precise correction with an explanation of its exceptional boundary, not a conjectural answer about these differences. Other statements in the linked sequence entries remain outside the note’s scope.
